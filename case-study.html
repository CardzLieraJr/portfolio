National Housing Authority — Balik Probinsya System

The Balik Probinsya, Bagong Pag-Asa Program is a flagship initiative of the Philippine Government designed to support families relocating from urban centers back to their provinces. To manage the scale and complexity of this effort, the National Housing Authority (NHA) required a centralized information system that could digitize manual processes, streamline beneficiary registration, and coordinate cross-departmental workflows.

Project Overview


As part of the NHA’s internal development team, I contributed to building a secure, organized, and scalable platform that improved operational efficiency and reduced reliance on paper-based processes. The system was designed to handle large volumes of beneficiary data while ensuring accuracy, security, and accessibility for administrators and staff.


Technical Focus

  • Database architecture: Optimized schema for bulk data handling and Excel imports
  • Deployment setup: Apache/PHP configuration tuned for stability and performance
  • Frontend interfaces: Responsive dashboards and user flows for administrators and operators
  • Workflow reliability: Structured CRUD operations and streamlined record management
  • Security: Role-based authentication and access control

Key Features

  • • Beneficiary registration and management
  • • Secure authentication and role-based access
  • • CRUD operations for records and applications
  • • Excel import and bulk data processing
  • • Camera integration for identity capture
  • • Responsive admin dashboard and user interface
  • • Real-time status tracking and workflow handling
